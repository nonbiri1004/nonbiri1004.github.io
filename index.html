關於我

從資料庫到前端，我都動手做過

我是 Jay，全端工程師。最近的工作是把 AI 圖片與影片生成整合進團隊的工作流程，做成大家打開就能用的工具。

在五人團隊的全端專題裡，我負責商品預購與獎品兌換兩個模組， 從資料表設計、ASP.NET Core Web API 到 Vue 3 前端，整條線自己走完。 兌換流程要同時扣點數、扣庫存、寫入紀錄，我讓它們在同一個交易裡一起成功或一起失敗。

我習慣把每個決定的理由想清楚，而不只是讓功能跑起來。合作時也一樣：做什麼、不做什麼、為什麼這樣做，開工前都會先講清楚。

怎麼開始合作

  1. 聊需求

    寄信簡單說明你想做什麼。我會先評估適合的做法，這一步不收費。

  2. 報價與範圍

    收到訂金後開始製作，過程中會定期讓你看進度，有問題可以及早調整。
