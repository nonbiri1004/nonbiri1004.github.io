關於我

從資料庫到前端，我都動手做過

在五人團隊的全端專題裡，我負責商品預購與獎品兌換兩個模組—— 從資料表關聯設計、ASP.NET Core Web API，到 Vue 3 前端串接，整條線自己走完。 其中兌換流程要同時扣點數、扣庫存、寫入紀錄， 我讓兩個 DbContext 共用同一條連線與同一個交易，確保三件事一起成功或一起失敗。

我習慣把每個決定的理由想清楚，而不只是讓功能跑起來—— 例如兌換紀錄裡的點數我刻意存當下的快照而不是即時查詢， 因為獎品點數之後會調整，但歷史紀錄不該跟著變。
